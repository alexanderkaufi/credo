## Hosting über GitHub Pages

Diese Website wird technisch über GitHub Pages bereitgestellt. GitHub Pages ist ein Hosting-Dienst für statische Websites, der Inhalte aus einem GitHub-Repository veröffentlicht.

Nach der offiziellen Dokumentation von GitHub wird beim Besuch einer GitHub-Pages-Website die IP-Adresse der Besucherinnen und Besucher zu Sicherheitszwecken protokolliert und gespeichert. Auf diese technische Verarbeitung durch GitHub haben wir nur insoweit Einfluss, als wir GitHub Pages als Veröffentlichungsplattform nutzen.

Rechtsgrundlage für die Nutzung des Hostings ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der sicheren und zuverlässigen Bereitstellung dieser Website.
