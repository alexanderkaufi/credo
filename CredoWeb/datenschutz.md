# Datenschutz

Dies ist aktuell eine Platzhalterseite.

Für eine öffentliche Website sollte hier später eine Datenschutzerklärung stehen, die zu deiner tatsächlichen Veröffentlichung passt.

## Später zu prüfen

- welche personenbezogenen Daten verarbeitet werden
- Hosting über GitHub Pages
- ob externe Dienste eingebunden sind
- ob Analyse- oder Tracking-Tools verwendet werden
- Kontaktwege und Rechtsgrundlagen

Hinweis: Diese Seite ist keine Rechtsberatung, sondern nur ein technischer Platzhalter für die spätere Veröffentlichung.
