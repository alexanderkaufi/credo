# Impressum

Dies ist aktuell eine Platzhalterseite.

Für eine öffentliche Website in Deutschland sollte hier später ein vollständiges Impressum mit den für dein Projekt nötigen Angaben stehen.

## Platzhalter

- Name oder Verantwortlicher
- Anschrift
- Kontaktmöglichkeit
- falls nötig: weitere gesetzlich erforderliche Angaben

Hinweis: Diese Seite ist keine Rechtsberatung, sondern nur ein technischer Platzhalter für die spätere Veröffentlichung.
